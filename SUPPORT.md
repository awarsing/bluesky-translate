# Support

Use GitHub Issues for public support:

<https://github.com/awarsing/bluesky-translate/issues>

## Before Opening An Issue

- Confirm the extension is enabled.
- Open Settings and run Test connection for your selected provider.
- Confirm your provider API key has available credits and model access.
- Clear the local translation cache, reload Bluesky, and retry.
- Never include API keys, screenshots containing keys, or provider billing details.

## Useful Details To Include

- Browser name and version.
- Extension version.
- Selected provider.
- Whether Test connection succeeds.
- A Bluesky post URL that reproduces the problem, if public.
- The exact error message shown by the extension, if any.
