# Bluesky Translator

Bluesky Translator is a bring-your-own-key browser extension that adds English translation cards below non-English posts on Bluesky.

This public repository is for support, release notes, privacy information, and GitHub Pages. It does not contain the extension source code.

## Links

- Releases: <https://github.com/awarsing/bluesky-translate/releases>

## What The Extension Does

- Detects visible Bluesky posts that appear to need English translation.
- Skips obvious English posts locally before any provider request.
- Sends only cleaned post text to your selected AI provider.
- Stores your provider API key, settings, usage counters, and translation cache locally in browser extension storage.
- Supports Groq, OpenAI, Google Gemini, and Anthropic with one active provider at a time.
