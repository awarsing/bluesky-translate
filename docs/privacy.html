Privacy Policy

Last updated: July 27, 2026

Overview

Bluesky Translator is a bring-your-own-key browser extension. Non-English posts are sent directly from your browser to your configured AI provider.

Local Data Storage

  • Extension state, including enabled or paused status.
  • Selected provider ID, provider default model, and API key.
  • Local translation cache entries.
  • Browser-local counters for posts examined, cache hits, token totals, and provider requests.

Provider Data Egress

Post text requiring translation is sent directly to your chosen AI provider endpoint using your stored API key. Data processing is governed by your provider account agreement.

Zero Telemetry

  • No analytics or tracking scripts.
  • No mandatory external user accounts.
  • No keys, prompts, or metrics transmitted to Three Things Media.
  • No data sale or monetization.

Extension Permissions

The extension requests storage permission for local settings, bsky.app host access for feed translation, and host access for supported provider API endpoints.

Support & Contact

Public support, releases, and issue tracking are available on GitHub.
